## 比較した票

2026-11-25にThe Computational Democracy Projectの公開データから、2会話の `comments.csv` と `participants-votes.csv` を取得した。ローカルのCLI試作（`codex/polis-cli`、`52a8f95d`）と同じ条件で、本文が空のコメントとモデレーションで除外されたコメントを除く。参加者ごとの最終票を使い、賛成を1、反対を−1、パスを0とし、未回答は別に保持した。元データはCC BY 4.0。[[source-code]]より。[ベーシックインカム（UBI）](https://github.com/compdemocracy/openData/tree/3be5785c3f5975d31f4578ee8bbf4426d45b7bf2/scoop-hivemind.ubi)・[シアトルの最低賃金](https://github.com/compdemocracy/openData/tree/3be5785c3f5975d31f4578ee8bbf4426d45b7bf2/15-per-hour-seattle)・[Polisの投票仕様](https://compdemocracy.org/vote/)

| 観測 | UBI | シアトル |
| --- | ---: | ---: |
| 名簿人数 / 対象コメントに1票以上ある人数 | 234 / 234 | 339 / 337 |
| 対象コメント / 票数（うちパス） | 70 / 7,153（812） | 31 / 2,849（592） |
| 投票のある参加者ペアのうち、共通回答が1件以下 | 9,302 / 27,261（34.1%） | 36,540 / 56,616（64.5%） |
| 平均補完UMAPで、画面上の近傍10人に共通回答が0件の組が占める割合 | 329 / 2,340（14.1%） | 683 / 3,370（20.3%） |
| 共通回答で距離を計算する試作の配置人数 / 名簿人数 | 183 / 234 | 165 / 339 |

画面上の近傍は各人から近い順に10人を選んで数えるため、同じ2人を両方向に含み得る。表の配置は乱数シード11。シアトルの位置保留174人の内訳は、共通回答の条件に届かない172人と、対象コメントへの票が0件の2人。どちらも比較画面で選択できる。

## 距離と検証

1. **投影法の比較**。未回答をコメントごとの平均で補完し、同じ行列をCLIのPCAとユークリッド距離のUMAPに渡した。PCAの全員の座標がCLI出力と一致することを確認した。
2. **共通回答を使う距離**。両者が答えた票について `(a−b)²/4` を足し、参加者ペア全体の平均損失を5票分足してから `共通回答数+5` で割り、平方根を取った。共通回答が5件未満の辺を除き、残る集団内で条件を満たす相手が15人未満の人を反復して配置対象から外した。同一の対象者に絞ったPCA・平均補完UMAPも作った。UMAPの `n_neighbors=15`、`min_dist=0.1`、300エポック、シード11・29・47を共通にした。[UMAPのパラメータ](https://umap-learn.readthedocs.io/en/latest/parameters.html)
3. **別のコメントでも賛否が似るか**。コメントを5組に分け、4組だけで対象者と地図を決めた。残りの各コメントに賛否を示した人について、地図上で近い他の回答者10人の賛成割合で本人の賛否をどれだけ判別できるかをAUCで測った。賛否各5人以上、回答者11人以上のコメントを等しく重み付けし、3シードを平均した。AUCは0.5で無作為相当、1で完全に判別できる。

| 同じ対象者での平均AUC | UBI（50コメント、6,025票） | シアトル（30コメント、1,877票） |
| --- | ---: | ---: |
| PCA | 0.683 | 0.709 |
| 平均補完UMAP | 0.693 | 0.679 |
| 共通回答で距離を計算するUMAP | 0.683 | 0.705 |

対象者をそろえた上で、画面上の近傍のうち共通回答が1件以下の組は、平均補完UMAPから共通回答UMAPに変えるとUBIで31組から17組、シアトルで95組から98組だった（シード11）。共通回答が乏しい組が減った効果の多くは、位置を保留した参加者がいることに由来する。2会話の傾向だけで距離やしきい値を採用する根拠には足りない。

## パスの解釈

パスを賛否の中間とする場合、賛成・反対・パスを互いに異なる3カテゴリとする場合、賛否を表明した票だけで向きを比べる場合を比較した。3方式で対象者と許される辺を同じにするため、この比較だけは双方が賛否を表明した共通回答5件を条件とした（UBI 181人、シアトル146人）。同じ乱数シードで中間値から3カテゴリへ変えたとき、図で近い10人のうち同じ相手が残るのは平均でUBI 3.6人、シアトル4.4人。中間値の扱いのままシードだけを変えた場合は、それぞれ5.9人、5.9人だった。入力自体にも同距離はあり、平均補完後の元空間で10番目と11番目の距離が等しい人は32人、53人だった。
