## 重要な判断

- **「似た機能がある」と「要件が満たされた」を混同しない**（[[issue-backlog-audit-2026-10-12]] の軸を踏襲）。[#592](https://github.com/digitaldemocracy2030/kouchou-ai/issues/592) は [#1150](https://github.com/digitaldemocracy2030/kouchou-ai/issues/1150) で接続エラーの説明文が入ったが Azure 固有の案内はまだ無い、[#973](https://github.com/digitaldemocracy2030/kouchou-ai/issues/973) は docs の受け入れ条件が起票前から満たされていた、など「一部解決」の中身を file:line で分けた
- **前回判定を信用しない**。[#809](https://github.com/digitaldemocracy2030/kouchou-ai/issues/809)（再現性オプションは定例で不採用と決まっていた）、[#558](https://github.com/digitaldemocracy2030/kouchou-ai/issues/558)（[#1056](https://github.com/digitaldemocracy2030/kouchou-ai/issues/1056) で解消）、[#323](https://github.com/digitaldemocracy2030/kouchou-ai/issues/323)（[#1144](https://github.com/digitaldemocracy2030/kouchou-ai/issues/1144) で主要部分が充足）は前回「未解決・一部解決」から動いた
- **assignee がいる issue は AI が着手しない**。実装が S でも [#337](https://github.com/digitaldemocracy2030/kouchou-ai/issues/337) / [#643](https://github.com/digitaldemocracy2030/kouchou-ai/issues/643) / [#513](https://github.com/digitaldemocracy2030/kouchou-ai/issues/513) は人間が継続意思を確認してから
- **実装候補は「設計判断を先取りしない形」に区切る**。[#60](https://github.com/digitaldemocracy2030/kouchou-ai/issues/60) は既定 OFF のトグル、[#213](https://github.com/digitaldemocracy2030/kouchou-ai/issues/213) は決定済みの案 3、[#576](https://github.com/digitaldemocracy2030/kouchou-ai/issues/576) は既定プロンプトでなく docs の調整例
