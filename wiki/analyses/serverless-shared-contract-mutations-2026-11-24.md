## 結果

[org PR #3](https://github.com/digitaldemocracy2030/kouchou-ai-serverless/pull/3) の共通プロパティベーステストは、**Python・TypeScriptともに意図的に作った14件の欠陥のうち12件を検出**した。残ったのは、公開JSONの `propertyMap` が存在しない意見を参照する変異と、Ward法の上位階層をすべて1群にする変異。

| 変異 | Python | TypeScript |
|---|---|---|
| 別回答の同文をまとめる、回答IDの先頭ゼロを消す | 2件を検出 | 2件を検出 |
| 所属先を存在しないIDにする、親階層を誤る、クラスタIDを重複させる | 3件を検出 | 3件を検出 |
| クラスタの意見数に1を足す、回答数を意見数で置き換える | 2件を検出 | 2件を検出 |
| 属性 `"01"` を数値にする、公開JSONから意見の属性を落とす | 2件を検出 | 2件を検出 |
| 元コメントの公開指定を無視する、内部用の入力名を公開設定へ含める | 2件を検出 | 2件を検出 |
| 上位階層が下位クラスタを分断する | 1件を検出 | 1件を検出 |
| 公開 `propertyMap` に存在しない意見IDを入れる | 生存 | 生存 |
| 上位階層をすべて1群にする | 生存 | 生存 |

root以外のクラスタの配列順を変える対照試験は両方とも通過した。配列の順番を合格条件にしていないことを確認した。対照試験は14件の分母に含めない。

## 残った検査の穴

- **公開属性表の参照切れ**。共通テストは `arguments[].attributes` の保持を調べるが、`propertyMap` の参照先は調べていない。Pythonの公開出力の既存テストはこの変異を検出し、ブラウザ版は全Vitest 248件が変異後も通過した。属性表の列を実装間で揃える必要はなく、出力された列に限ってキーが実在の `arg_id` を指すことを検査できる。
- **上位階層の分割数**。共通テストは距離が同点のときに分割数が少なくなることを許すため、すべての上位階層が常に1群でも通過する。Python・ブラウザ版ともに既存のクラスタリング単体テストは検出した。共通テストで補う場合は、分割数が確定する点群を追加し、番号や並びを比較せず上位の群数を調べる。
